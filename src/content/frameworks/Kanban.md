# Kanban

## O que é

Kanban é um método de gestão visual do trabalho baseado na visualização das atividades, limitação do trabalho em progresso e melhoria contínua do fluxo.

Sua origem está associada ao sistema de produção da Toyota, especialmente ao sistema de produção Just-in-Time.

## Para que serve

Serve para visualizar o trabalho, identificar gargalos, controlar o volume de atividades em andamento e melhorar o fluxo de processos.

## Quando utilizar

É especialmente útil quando uma empresa possui:

- excesso de tarefas simultâneas;
- gargalos operacionais;
- baixa visibilidade dos processos;
- atrasos frequentes;
- dificuldade de priorização;
- equipes sobrecarregadas.

## Como aplicar

Comece mapeando o fluxo real do trabalho e transformando cada etapa em uma coluna visual.

Um modelo simples:

**A fazer → Em andamento → Em revisão → Concluído**

Depois, estabeleça limites para o número de tarefas simultâneas em cada etapa.

## Etapas

1. Mapear o fluxo atual.
2. Criar o quadro Kanban.
3. Criar cartões para as atividades.
4. Definir limites de trabalho em progresso.
5. Acompanhar o fluxo.
6. Identificar gargalos.
7. Melhorar continuamente o processo.

## Exemplo de aplicação

Uma software house pode utilizar Kanban para controlar:

**Backlog → Desenvolvimento → Testes → Homologação → Produção**

Se muitas tarefas se acumularem em "Testes", o gargalo torna-se visual e a empresa pode atuar sobre ele.

## Vantagens

- Fácil implementação.
- Baixo custo.
- Alta visibilidade.
- Identificação rápida de gargalos.
- Flexível.
- Pode ser utilizado em praticamente qualquer setor.

## Limitações

- Um quadro Kanban não resolve problemas estruturais sozinho.
- Pode virar apenas uma ferramenta de acompanhamento de tarefas.
- Não define necessariamente prioridades estratégicas.
- Exige disciplina para controlar o trabalho em progresso.
